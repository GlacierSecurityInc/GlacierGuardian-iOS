# Active cellular ICE policy checks

Run `bash Scripts/ICEInterfacePolicyTests/run.sh` for the device-derived interface eligibility regression. It checks both address families, active-interface changes, cold-start exclusion, multi-digit names and preservation of Wi-Fi/VPN/loopback entries.

Run `bash Scripts/ICEInterfacePolicyTests/run_sdk.sh <macOS-framework-directory>` with the macOS slice of the pinned WebRTC XCFramework. This exercises real ICE gathering, checks that it calls the filter, and checks that the application's own `getifaddrs` import remains untouched.

The current public WebRTC API has no per-interface allowlist. Its native Apple monitor initially permits all interfaces until the asynchronous path update arrives. Glacier starts two Network.framework path monitors at launch, the default path and the cellular-only path, and filters only the WebRTC image's private interface snapshot. The allowed cellular interface is the default path's when the app is on cellular; while Wi-Fi is the default, it is the cellular-only path's, so ICE keeps the primary cellular context as a backup. Auxiliary cellular contexts are hidden in both cases. The first WebRTC enumeration or bind waits up to 200 ms, once, for both monitors' first reports so a call right after a cold launch sees the correct cellular interface. When neither path is known, no cellular interfaces are exposed; non-cellular interfaces remain unchanged. The allowed interface comes from the system paths, not a hardcoded `pdp_ip0` index. Explicit socket source bindings also pass through the SDK-scoped guard, which rejects inactive cellular addresses with EADDRNOTAVAIL. Both direct and group calls share the same factory and policy. WebRTC's normal network-change/polling behavior refreshes enumeration during handoff.

No OS interface flags, routes, sockets in other SDKs, encryption settings or server configuration are changed. On an unsupported SDK image layout, cellular ICE is disabled rather than silently reopening auxiliary contexts. Physical acceptance must verify the installation log, actual WebRTC enumeration, no ICE/STUN traffic on inactive cellular interfaces, setup time and working two-way audio.

The image-scoped rebinder is adapted from [fishhook](https://github.com/facebook/fishhook/tree/aadc161ac3b80db07a9908851839a17ba63a9eb1). The original BSD license is included beside the source. Local changes namespace the API, remove process-wide rebinding, count successful writes and restore original memory-page protections immediately (logging rather than aborting if a restore fails). `GlacierTests/GlacierICEInterfacePolicyTests.m` fails if the rebinding stops installing after an SDK upgrade. Replace the adaptation with an upstream supported allowlist when the SDK exposes one.
